ggl_container

Stabilized index-1 Gear-Gupta-Leimkuhler-inspired (GGL) reduction for mechanical systems with autonomous holonomic constraints.

For autonomous holonomic constraints , this variant uses coordinates , velocities , force multipliers , and kinematic multipliers in the formulation where . Thus and . Consistent constraints remain zero in the exact solution; positive gains damp violations. Numerical integration and interpolation do not project onto the constraints.

Unlike classical index-2 GGL, the original position and velocity constraints are replaced by their stabilized evolution equations. The algebraic multipliers are locally determined when and are nonsingular. Independent constraints and a symmetric positive-definite mechanical mass matrix suffice. Explicitly moving constraints are not supported: the constraint callbacks must not depend on the independent variable.

abstract interface

  • public subroutine dae_algebraic_constraints(x, y, g, args)

    Evaluates algebraic constraint residuals .

    For input state components and constraints, the callback represents a mapping A consistent state satisfies . Return the residuals themselves, not their derivatives, a Boolean result, or a projected state. A nonzero residual is a valid evaluation at an inconsistent state, rather than a callback failure.

    The caller supplies the input and output array sizes. The implementation must interpret the same state ordering as its model and write every output element. This interface performs no dimension, rank, or initial-consistency checks. Residual ordering and physical units are defined by the model; any subsequent consistency tolerance must respect that scaling.

    Arguments

    Type IntentOptional Attributes Name
    real(kind=real64), intent(in) :: x

    The independent-variable value at which to evaluate the constraints, normally time. Autonomous constraints may ignore this argument.
    real(kind=real64), intent(in), dimension(:) :: y

    An N-element input state in the ordering defined by the model. No particular coordinate, velocity, or multiplier partition is imposed by this interface. It must not be modified by the callback.
    real(kind=real64), intent(out), dimension(:) :: g

    An M-element output array receiving the constraint residuals in the model's declared constraint order. Every element must be assigned on every call; incoming contents are undefined. Exact constraint satisfaction corresponds to a zero vector.
    class(*), intent(inout), optional :: args

    Optional user-owned model parameters or evaluation state. Check presence and dynamic type before accessing it. The callback may update this object, but repeated calls with the same inputs should give the same residuals unless the user intentionally changes model parameters. This argument is not reserved for index-reduction workspace.
