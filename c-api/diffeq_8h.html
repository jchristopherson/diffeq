◆ c_dae_algebraic_constraints

typedef void(* c_dae_algebraic_constraints) (int nconstraints, int nstates, double x, const double *y, double *g)

Evaluates algebraic constraint residuals \(g(x,y)\).

For \(N\) input state components and \(M\) constraints, the callback represents a mapping

\[ g : \mathbb{R}\times\mathbb{R}^{N} \longrightarrow \mathbb{R}^{M}. \]

A consistent state satisfies \(g(x,y)=0\). Return the residuals themselves, not their derivatives, a Boolean result, or a projected state. A nonzero residual is a valid evaluation at an inconsistent state, rather than a callback failure.

The caller supplies the input and output array sizes. The implementation must interpret the same state ordering as its model and write every output element. This interface performs no dimension, rank, or initial-consistency checks. Residual ordering and physical units are defined by the model; any subsequent consistency tolerance must respect that scaling.

Parameters
nconstraintsThe number of constraint equations.
nstatesThe number of state variables.
xThe current value of the independent variable.
yThe current state vector.
gThe constraint vector.

◆ c_dae_constraint_curvature

typedef void(* c_dae_constraint_curvature) (int nconstraints, int nstates, double x, const double *q, const double *direction, const double *v, double *curvature)

Evaluates \(DG(q)[\mathrm{direction}]v\), without including \(G\dot v\).

Each component is \(\mathrm{direction}^T\nabla^2 g_i(q)v\). Assign every output element. For linear constraints return zeros. The callback must support off-manifold coordinates and arbitrary directions used during nonlinear/Jacobian evaluation.

Parameters
nconstraintsThe number of constraint equations.
nstatesThe number of state variables.
xThe current value of the independent variable.
qThe current coordinate vector.
directionThe coordinate derivative \(\dot q\), including the kinematic multiplier correction.
vThe physical velocity components.
curvatureThe curvature terms in the order of teh constraint callback.
