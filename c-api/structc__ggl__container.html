Detailed Description

Describes a holonomically constrained mechanical model to be solved with the stabilized index-1 Gear-Gupta-Leimkuhler (GGL) formulation.

For N coordinates and M constraints the integrated state is \(z = [q_N, v_N, \lambda_M, \mu_M]^T\), so the nstates argument supplied to the DAE integrators must equal \(2(N + M)\), and the initial conditions must use this ordering. The model is

\[ \dot q = v + G^T\mu, \qquad M(q)\dot v = F(x,q,v) - G^T\lambda, \]

\[ 0 = G\dot q + \alpha g, \qquad 0 = DG(q)[\dot q]v + GM^{-1}(F - G^T\lambda) + \beta Gv, \]

where \(g(q)\) are the position constraints and \(G = \partial g / \partial q\). Every callback must accept perturbed, off-manifold states, and the constraint callbacks must not depend on the independent variable.

Member Data Documentation

◆ force

c_ode c_ggl_container::force

Required callback computing the applied force \(F(x,q,v)\), excluding multiplier forces.

It is called with n = 2N and receives the 2N-element vector [q, v], but must write only the N-element force vector.

◆ jacobian

c_ode_jacobian c_ggl_container::jacobian

Optional callback for computing the Jacobian matrix of the complete system, including the constraints.

If not supplied, the Jacobian will be estimated with finite differences.

◆ mass

c_ode_mass_matrix c_ggl_container::mass

Optional callback receiving the N-element coordinate vector q and writing the N-by-N symmetric positive-definite physical mass matrix.

Set to NULL to use the identity matrix. Set the mass_matrix_constant setting to false whenever this matrix varies with x or q.

◆ constraints

c_dae_algebraic_constraints c_ggl_container::constraints

Required callback receiving the N-element coordinate vector q and writing the M position constraint residuals \(g(q)\).

◆ gradient

c_ode_jacobian c_ggl_container::gradient

Required callback receiving the N-element coordinate vector q and writing the M-by-N constraint Jacobian \(G = \partial g / \partial q\) in column-major order.

The rows of \(G\) must be linearly independent.

◆ curvature

c_dae_constraint_curvature c_ggl_container::curvature

Required callback computing the M curvature terms \(DG(q)[\dot q]v\).

Return zeros for linear constraints.

◆ events

c_ode_event_function c_ggl_container::events

Optional callback for enabling event detection.

The callback receives the full augmented state, including multipliers. A NULL callback or an event_equation_count less than one disables event detection.

◆ alpha

double c_ggl_container::alpha

Nonnegative, finite position-constraint decay rate, in inverse independent-variable units.

Zero disables position damping.

◆ beta

double c_ggl_container::beta

Nonnegative, finite velocity-constraint decay rate, in inverse independent-variable units.

Zero disables velocity damping.

◆ constraint_count

int c_ggl_container::constraint_count

The number M of independent constraints, with 1 <= M <= N.

◆ event_equation_count

int c_ggl_container::event_equation_count

The number of event equations in events.

This value must be greater than zero when event detection is intended.
