public interface operator(**)

Exponentiation with constant or variable base/exponent. Variable exponents require a positive base, except that a zero constant base with a positive exponent has zero derivative. Constant integral exponents also support negative bases.

private elemental function ad_power(a, b) result(c)

Apply d(ab) = b*a(b-1)da + ablog(a)*db. Omit inactive terms so constant powers work at zero and negative bases.

private elemental function ad_power_integer(a, b) result(c)

Evaluate an integer power, preserving negative-base and zero-base behavior. Negative exponents avoid b-1, which could overflow the integer range.
