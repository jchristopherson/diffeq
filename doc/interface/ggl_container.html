private function ggl_constructor_1(coordinate_count, constraint_count, alpha, beta) result(rst)

Defines the mechanical dimensions and resets stabilization gains to one unless supplied. Callback associations and inherited model options are retained. Invalid counts or gains cause DIFFEQ_INVALID_INPUT_ERROR.

Arguments

Type IntentOptional Attributes Name
integer, intent(in) :: coordinate_count

Positive number N of coordinates and physical velocities.
integer, intent(in) :: constraint_count

Number M of independent constraints, with 1 <= M <= N.
real(kind=real64), intent(in), optional :: alpha

Nonnegative finite position and velocity decay rates, respectively, in inverse independent-variable units. Zero disables the respective damping term without disabling the differentiated constraint.
real(kind=real64), intent(in), optional :: beta

Nonnegative finite position and velocity decay rates, respectively, in inverse independent-variable units. Zero disables the respective damping term without disabling the differentiated constraint.

Return Value type(ggl_container)

The new ggl_container object.
