procedure, public :: find_event => oes_find_event

Attempts to find any events within a specified bracket.

  • private function oes_find_event(this, fcn, integrator, neqn, x1, y1, x2, y2, x, y, args) result(rst)

    Attempts to find an event via Brent's method for root finding for each of the M event equations (M does not have to be equal to the number of state equations). If no events are found, this function simply returns false. If a root, or roots, are found, the first occurring root is returned, and iteration statistics are updated in the ode_event_solver. A root at the initial bound is ignored so an integration restarted at an event can advance; a root at the terminal bound is still reported.

    If no event function has been defined a DIFFEQ_NULL_POINTER_ERROR is thrown.

    procedure(ode_event_function), intent(in), pointer :: fcn

    The ode_event_function.
    class(ode_integrator), intent(in) :: integrator

    The ode_integrator being used to integrate the ODE's.
    integer, intent(in) :: neqn

    The number of event equations. This value must be at least 1; else, a DIFFEQ_INVALID_INPUT_ERROR is thrown.
    real(kind=real64), intent(in) :: x1

    The initial bound of the search region.
    real(kind=real64), intent(in), dimension(:) :: y1

    The N-element state vector at x1.
    real(kind=real64), intent(in) :: x2

    The terminal bound of the search region. This value must be different than x2 by an amount larger than machine epsilon; else, a DIFFEQ_INVALID_OPERATION_ERROR is thrown.
    real(kind=real64), intent(in), dimension(:) :: y2

    The N-element state vector at x2. This array must be sized to match x1; else, a DIFFEQ_ARRAY_SIZE_ERROR is thrown.
    real(kind=real64), intent(out) :: x

    The value of the independent variable at which the root is found. If no root is found, this value is returned as a NaN.
    real(kind=real64), intent(out), dimension(:) :: y

    The N-element array containing the state vector at x. If no root is found, this array is populated with NaN. This array must be sized to match x1; else, a DIFFEQ_ARRAY_SIZE_ERROR is thrown.
    class(*), intent(inout), optional :: args

    An optional argument that can be used to pass information in and out of the routine.

    Return Value logical

    True if the process converged to a root; else, false.
