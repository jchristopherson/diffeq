procedure(ode_ad), public, pointer, nopass :: fcn_ad => null()

A pointer to the routine containing the ODEs to integrate. Use this pointer instead of fcn when automatic differentiation is desired for calculation of the Jacobian. Do not use both pointers as this will produce an error. If fcn is utilized, then the Jacobian will be computed by either a user-supplied Jacobian callback or by finite differences. If this pointer is utilized, then the Jacobian will be computed by either a user-supplied Jacobian callback or automatic differentiation. In either case a user-supplied Jacobian callback is the preferred option falling back to either finite differences or automatic differentiation in its absence.
procedure(ode_jacobian), public, pointer, nopass :: jacobian => null()

A pointer to the routine containing the analytical Jacobian. Takes precedence over AD and finite differences. If null, the selected RHS representation determines the differentiation method.
procedure(ode_mass_matrix), public, pointer, nopass :: mass_matrix => null()

A pointer to the routine containing the mass matrix for the system. If set to null (the default), an identity mass matrix will be assumed.

procedure, public :: compute_jacobian => oc_jacobian

  • private subroutine oc_jacobian(this, x, y, jac, args)

    Computes df/dy, holding x fixed. Uses an explicit Jacobian if supplied, otherwise AD (N RHS calls) or forward differences (N+1 RHS calls). The most recent callback count is available through get_jacobian_function_evaluations. An explicit Jacobian counts as zero RHS calls; calls made inside user-owned Jacobian code are not tracked.

procedure, public :: compute_time_derivative => oc_time_derivative

  • private subroutine oc_time_derivative(this, x, y, f, dfdx, args)

    Computes partial df/dx with y fixed, using one RHS callback evaluation. AD seeds x only. Real callbacks use a forward difference with the supplied unperturbed RHS f. Mass-matrix derivatives are not included.
