write_ode_results diffeq_container_io Subroutine

Writes the contents of a ode_results container to a delimited text file, replacing any existing file. Each row contains the independent variable followed by the state variables, without a header. An initialized empty container produces an empty file. Invalid delimiters cause DIFFEQ_INVALID_INPUT_ERROR; uninitialized containers and file I/O failures cause DIFFEQ_INVALID_OPERATION_ERROR.
