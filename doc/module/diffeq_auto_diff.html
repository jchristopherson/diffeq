Derived Types
real_ad

First-order forward automatic differentiation for Jacobian expressions.

Each real_ad stores one value and one directional derivative. Reevaluate an expression with one independent variable seeded at a time to obtain Jacobian columns. All overloads are elemental and preserve scalar expansion. Arithmetic and comparisons accept real_ad, real(real64), and default integer operands; binary intrinsics accept real_ad and real(real64).

Comparisons ignore derivatives. ABS uses derivative zero at zero; MIN/MAX are binary and retain the first argument on ties. SIGN differentiates only its magnitude argument. These are branch conventions, not derivatives at discontinuities. Other domain errors and singular derivatives follow the underlying real intrinsics and the caller's floating-point error settings.

In the procedures below, a/b (or y/x for ATAN2) are input operands, c is the result, and dx is propagated by the chain rule. Real and integer operands are constants with derivative zero.


Uses

    • iso_fortran_env
