public function c_adams(nx, nstates, fcn, x, initcond, settings, mass, output) result(rst) bind(C, name = "c_adams")

Utilizes a variable order Adams predictor-corrector integrator to solve a system of first order differential equations.

Arguments

Type IntentOptional Attributes Name
integer(kind=c_int), intent(in), value :: nx

The number of solution points. This value must be at least 2; else, a C_INVALID_INPUT_ERROR is returned.
integer(kind=c_int), intent(in), value :: nstates

The number of state equations. This value must be at least 1; else, a C_INVALID_INPUT_ERROR is returned.
type(c_funptr), intent(in), value :: fcn

A pointer to the function containing the equations to integrate.
real(kind=c_double), intent(in) :: x(nx)

An NX-element array containing the desired solution points.
real(kind=c_double), intent(in) :: initcond(nstates)

An NSTATES-element array containing the initial conditions.
type(c_ode_settings), intent(in) :: settings

The integrator settings.
type(c_funptr), intent(in), value :: mass

A pointer to the routine for computing the mass matrix. Pass NULL if no routine is necessary. This routine cannot handle singular mass matrices.
type(c_ptr), intent(out) :: output

The output c_ode_results object. Memory must be freed by c_free_ode_results.

Return Value integer(kind=c_int)

An error flag denoting the status of the operation.
