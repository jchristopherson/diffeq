type, public, extends(ode_container) :: ggl_container

Mechanical model adapter implementing stabilized index-1 GGL.

Use this type instead of ode_container when reducing an index-3 holonomically constrained mechanical model. Call initialize and assign all required callbacks before using an index-1 DAE solver. For N coordinates and M constraints, the state and RHS layout is All constraint vectors use the same M-component ordering.

The inherited fcn has a specialized contract here: its input is [q,v] of length 2N and its output is the applied force F of length N, excluding multiplier forces. The optional inherited mass_matrix receives q of length N and writes the physical N-by-N mass matrix; if absent, the physical matrix is identity. Set the inherited mass dependency flag true whenever this matrix varies with x or q.

An optional inherited jacobian must differentiate the complete augmented RHS with respect to z, not just the applied force. Without it, the inherited finite-difference implementation differentiates this container's compute_rhs. User args are never used as internal workspace. Callbacks must accept perturbed, off-manifold states. The inherited fcn_ad is not supported: differentiating only the applied force would omit the real-valued constraint assembly. Assigning fcn_ad causes DIFFEQ_INVALID_OPERATION_ERROR.

  • private subroutine oc_jacobian(this, x, y, jac, args)

    Computes df/dy, holding x fixed. Uses an explicit Jacobian if supplied, otherwise AD (N RHS calls) or forward differences (N+1 RHS calls). The most recent callback count is available through get_jacobian_function_evaluations. An explicit Jacobian counts as zero RHS calls; calls made inside user-owned Jacobian code are not tracked.

    An N-element array containing the current dependent variable values.

    An N-by-N matrix where the Jacobian will be written.

procedure, public :: compute_rhs => ggl_rhs

  • private subroutine ggl_rhs(this, x, y, dydx, args)

    Assembles the four RHS blocks documented on ggl_container. The output is a mass-matrix RHS, not the full derivative z'. Only the physical mass is resolved to compute the acceleration residual. Missing callbacks cause NULL_POINTER; invalid state/output lengths cause INVALID_INPUT/ARRAY_SIZE; singular physical mass causes SINGULAR_MATRIX.

    Arguments

    Type IntentOptional Attributes Name
    class(ggl_container), intent(inout) :: this

    Initialized container with all required callbacks assigned.
    real(kind=real64), intent(in) :: x

    Current independent-variable value.
    real(kind=real64), intent(in), dimension(:) :: y

    State [q,v,lambda,mu] of length 2N+2M; off-manifold values are allowed.
    real(kind=real64), intent(out), dimension(:) :: dydx

    2N+2M RHS entries, ordered as kinematics, momentum, stabilized position residual, and stabilized velocity residual.
    class(*), intent(inout), optional :: args

    Optional user parameters forwarded unchanged to every callback.

procedure, public :: validate_initial_conditions => ggl_validate

  • private function ggl_validate(this, x, y, tolerance, args) result(rst)

    Checks max(abs(g)) and max(abs(Gv)) against one absolute tolerance. This tests physical position/velocity consistency, not the multiplier equations, and never changes the state. Choose units/scaling so one tolerance is meaningful for both residuals. Nonfinite residuals fail.

    Arguments

    Type IntentOptional Attributes Name
    class(ggl_container), intent(inout) :: this

    Initialized container; only constraints and their Jacobian are needed.
    real(kind=real64), intent(in) :: x

    Independent-variable value passed to the callbacks.
    real(kind=real64), intent(in), dimension(:) :: y

    Augmented initial state of length 2N+2M.
    real(kind=real64), intent(in) :: tolerance

    Finite nonnegative absolute residual threshold; invalid values cause DIFFEQ_INVALID_INPUT_ERROR.
    class(*), intent(inout), optional :: args

    Optional user parameters forwarded without using internal workspace.

    Return Value logical

    True when both physical residuals are finite and within tolerance.
